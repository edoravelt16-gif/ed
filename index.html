Fitur Rekonsiliasi Multi-File

1
Penggabungan Otomatis

Menggabungkan seluruh baris data dari multiple file DOM dan FB DOM tanpa batasan jumlah file.

2
Pelacakan Nama File Sumber

Setiap baris data ditandai dengan nama file asalnya sehingga laporan dapat difilter per file.

3
Cross-Matching Lintas File

Status GR dan selisih kuantitas dicocokkan di seluruh file yang diunggah secara instan.

Keamanan Data Terjamin

Seluruh pemrosesan multiple file dilakukan secara aman di browser Anda. Data tidak diunggah ke server pihak ketiga.
